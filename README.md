# 📊 Employee Attendance Tracker Dashboard

## 📌 Project Overview

The Employee Attendance Tracker Dashboard is an Excel-based analytics project designed to monitor employee attendance, absenteeism, punctuality, and working hours using interactive dashboards and visual reports.

---

## 🎯 Objective

This project helps analyze:

* Attendance performance
* Absenteeism trends
* Employee punctuality
* Working hour patterns

---

## 🛠️ Tools & Features Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* KPI Dashboard
* Conditional Formatting
* Data Validation

---

## ⚡ Advanced Excel Features Used

### ✅ Data Validation

Used dropdown validation to allow only valid entries and avoid data inconsistency.

**Examples:**

* Status → Present / Absent / Work From Home
* Department → IT / HR / Finance / Sales / Operations

**Benefits:**

* Prevents invalid data entry
* Improves data accuracy
* Keeps dataset standardized

### 🎨 Conditional Formatting

Used conditional formatting to highlight important records visually.

**Applied on:**

* Present → Green
* Absent → Red
* Work From Home → Blue
* On Time → Green
* Late → Orange

**Benefits:**

* Quick visual analysis
* Easy error detection
* Professional dataset presentation
